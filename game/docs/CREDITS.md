# แหล่งที่มาและสิทธิ์ใช้งาน

## Assets
- โมเดล 3D ทั้งหมดเป็นรูปทรงพื้นฐานของ Three.js สร้างในโค้ด (`src/game/world.ts`) ไม่มีไฟล์โมเดลภายนอก
- พื้นผิวพิกเซลทั้งหมดวาดด้วยโค้ด (`src/render/textures.ts`) ไม่มีรูปภาพภายนอก
- เสียงประกอบสังเคราะห์สดด้วย WebAudio ในโค้ด (`src/audio/sfx.ts`) ไม่มีไฟล์เสียงภายนอก, ยังไม่มีเพลง
- เนื้อเรื่อง ชื่อตัวละคร และบทพูดเขียนขึ้นใหม่สำหรับโปรเจกต์นี้ ไม่ได้คัดลอกจาก Harvest Moon หรือเกมอื่น
