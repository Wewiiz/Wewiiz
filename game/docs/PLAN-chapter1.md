# แผนสร้างบทที่ 1 "บ้านเก่า"

แนวคิด: สร้างบ้าน → เปลี่ยนชีวิต → ฟื้นเมือง  ·  เป้าความยาว 20–30 นาที (ต้องจับเวลาจริงตอนทดสอบ ไม่ยืดด้วยการรอ)

> หมายเหตุ: ในโปรเจกต์ยังไม่มีเอกสารออกแบบเกมฉบับเต็ม (ไฟล์แนบที่พบเป็นภาพหน้าจอการตั้งค่า GitHub เท่านั้น)
> ชื่อตัวละคร บทพูด และรายละเอียดเรื่องด้านล่างจึงเป็นค่าตั้งต้น เปลี่ยนได้ทันทีเมื่อได้เอกสารต้นฉบับ

## หลักที่ใช้ตลอด
- mesh / material / texture สร้างครั้งเดียวแล้วใช้ร่วมกัน (`ps1Material`, `tex.*`)
- ความละเอียดภายใน 240 เส้น ขยายแบบ pixelated, หมอกสีอบอุ่น กล้องตามหลังตัวละครให้มองเห็นชัด
- เซฟแยก `story` (ธงเรื่องราว) ออกจาก `inventory` (จำนวนของ) และ `world`; ตรวจทุกช่องก่อนโหลด; ไม่เขียนทับเซฟเสียถ้าผู้เล่นไม่ยืนยัน และสำรองไว้ก่อนเสมอ
- เปลี่ยนรูปแบบเซฟเมื่อไรต้องเพิ่ม `SAVE_VERSION` และเขียนตัวแปลงจากเวอร์ชันเก่า
- ไม่มี multiplayer, marketplace หรือเงินจริง
