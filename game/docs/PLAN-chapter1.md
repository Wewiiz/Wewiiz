## เส้นเรื่อง

1. **จดหมายของคุณตา** มาถึงทางเข้าไร่ที่หมู่บ้านดอยฝน
2. **ป้าบุญ** (ผู้ดูแลบ้าน) รอที่ประตูรั้ว อธิบายสภาพบ้านและวิธีทำไร่ มอบเครื่องมือกับเมล็ด 6 ซอง
3. **วัน 1–4** ปลูก รดน้ำ เก็บไม้และหิน ฝนตกวันที่ 3 เก็บเกี่ยววันที่ 4 ส่งขาย
4. **ซ่อมบ้าน** เมื่อของครบ (เร็วสุดราววันที่ 5) ป้าบุญกับเพื่อนบ้านมาช่วยจนเย็น ไฟในบ้านติดเป็นครั้งแรกในรอบสิบปี
5. **นิดกลับมาเยี่ยม** เช้าวันถัดไปที่ทางเข้าหมู่บ้าน เห็นแสงไฟจากบ้าน เล่าว่าห้วยเย็นแห้ง หมู่บ้านจึงร้าง บอกวิธีเปิดหีบของคุณตา
6. **เบาะแส** จดหมายและแผนที่ในหีบ: ดินถล่มปิดทางน้ำบนเขา ไม่ใช่น้ำแห้งหาย
7. **ทางเลือก** กับนิด
   - *อยู่ฟื้นฟูไร่และบ้านให้มั่นคงก่อน* → นิดอยู่ช่วยที่ไร่ ได้เมล็ด +5 · ฉากจบ "บ้านที่มีคนอยู่" · บทถัดไป: ฤดูเก็บเกี่ยวแรก
   - *ออกเดินทางตามหาห้วยเย็น* → นิดออกไปรอที่ทางขึ้นเขา ป้ายทางแยกเปลี่ยน · ฉากจบ "ตามรอยห้วยเย็น" · บทถัดไป: ต้นน้ำที่หายไป
8. หลังฉากจบเลือก "ใช้ชีวิตในไร่ต่อ" ได้

|---|---|---|
| 0 | โครงโปรเจกต์ เรนเดอร์ PS1 ฟอนต์ไทย ระบบเซฟ + ตัวตรวจ | ✅ |
| 1 | ชนวัตถุ, เข้า/ออกบ้าน, ป้ายเป้าหมาย, กรอบเล็งช่องแปลง | ✅ |
| 2 | เก็บไม้/หิน, งอกใหม่รายคืน | ✅ |

| 4 | ซ่อมบ้าน ภาพก่อน/หลังทั้งนอกและใน | ✅ |
| 5 | บทสนทนาไทย มีตัวเลือก, ร้านเมล็ด, ความสนิท | ✅ |
| 6 | ผู้กลับมาเยี่ยม + เบาะแส | ✅ |

| 8 | หน้าแรก เล่นต่อ/เริ่มใหม่/วิธีเล่น, เสียงสังเคราะห์, กลางวัน/กลางคืน/ฝน | ✅ |

## งานค้าง
- ให้คนเล่นจริงจับเวลาและปรับสมดุล (เป้า 20–30 นาที ดูตัวเลขประมาณใน TEST-REPORT)
- ทดสอบบน Windows/macOS กับ Chrome, Edge, Firefox, Safari
- ยังไม่มีเพลงประกอบ, ยังไม่มีอนิเมชันเครื่องมือแยกตามชนิด (ตอนนี้แกว่งแขนแบบเดียว)
- รองรับจอสัมผัส/มือถือ (ตอนนี้คีย์บอร์ด+เมาส์เท่านั้น)
- เนื้อเรื่องจริงจากเอกสารต้นฉบับเมื่อได้รับ
