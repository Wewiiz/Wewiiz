### รายการใน `npm run smoke`
หน้าแรกไม่มี error → เริ่มเกมใหม่ อ่านจดหมาย → คุยป้าบุญได้เครื่องมือ → พรวน หว่าน รดน้ำ 6 ช่อง → ขวาน/ค้อนได้ไม้/หิน → นอนแล้วขึ้นวันใหม่และบันทึกอัตโนมัติ → วันที่ 3 ฝนรดน้ำให้ → เก็บเกี่ยว 6 หัว → ส่งขาย → ได้เงินตอนเช้า 360 → ซ่อมบ้าน → พบนิด → เปิดหีบได้เบาะแส → เลือกทาง → ฉากจบ → ฉากจบถูกบันทึก → ปิดหน้าแล้วเปิดใหม่ หน้าแรกขึ้น "เล่นต่อ (วันที่ 6)" → เล่นต่อได้สถานะจบบท → K บันทึก/L โหลดตำแหน่งถูก → เซฟที่มีเงินติดลบและไม้เป็นข้อความถูกแจ้งบนหน้าแรกและปุ่มเล่นต่อถูกปิด → บันทึกครั้งแรกไม่ทับเซฟเสีย → ยืนยันครั้งที่สองทับได้และมีสำรอง → ไม่มี error ตลอดการทดสอบ

การทดสอบนี้กดปุ่มจริงทุกการกระทำ แต่ใช้ตัวช่วยทดสอบย้ายตำแหน่งตัวละครแทนการเดิน จึงเร็วกว่าคนเล่นมาก

## ข้อจำกัด
- เซฟอยู่ใน localStorage ของเบราว์เซอร์นั้นเครื่องนั้น ล้างข้อมูลเว็บแล้วเซฟหาย โหมดส่วนตัวอาจบันทึกไม่ได้ (เกมแจ้งเป็นข้อความและยังเล่นได้)
- คีย์บอร์ดและเมาส์เท่านั้น ยังไม่รองรับจอสัมผัส
- เสียงประกอบเริ่มหลังกดปุ่มหรือคลิกครั้งแรก (ข้อกำหนดของเบราว์เซอร์)
