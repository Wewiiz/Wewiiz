# ผลทดสอบ

วันที่ทดสอบ: 2026-10-04 · เครื่อง: Linux container บนคลาวด์ (ไม่ใช่เครื่องผู้ใช้)

## สิ่งที่รันจริง
| การทดสอบ | คำสั่ง | ผล |
|---|---|---|
| ตรวจชนิดข้อมูล | `npm run typecheck` | ผ่าน |
| เทสต์ระบบเซฟ 23 ข้อ (ค่าผิดประเภท ตัวเลขเกินขอบเขต JSON เสีย ไม่เขียนทับเซฟเสีย สำรองก่อนทับ พื้นที่เต็ม) | `npm test` | ผ่าน 23/23 |
| build | `npm run build` | ผ่าน (JS 545 kB, gzip 138 kB) |
| เปิดเกมจริงใน Chromium (headless, WebGL ผ่าน SwiftShader) | `npm run smoke` | ผ่าน 8/8 |

รายการใน smoke test: เริ่มเกมไม่มี error, กด W แล้วตัวละครเดิน, บันทึกแล้วขึ้นข้อความไทย, ปิดหน้าแล้วเปิดใหม่โหลดตำแหน่งเดิม, เซฟที่มีค่าเกินขอบเขตถูกแจ้งเตือนและไม่โหลด, ค่าเสียไม่เข้าเกม, กดบันทึกครั้งแรกไม่ทับเซฟเสีย, กดยืนยันครั้งที่สองทับได้และมีสำรอง

## เบราว์เซอร์ที่ทดสอบจริง
- Chromium 141 (Playwright 1.56, headless) บน Linux เท่านั้น

ยังไม่ได้ทดสอบ: Chrome/Edge/Firefox/Safari บน Windows หรือ macOS, การ์ดจอจริง, เวลาเล่นบทที่ 1 (บทยังไม่ครบ)

## ข้อจำกัดตอนนี้
- เป็นโครงต้นแบบ: ยังไม่มีเก็บของ ปลูก เปลี่ยนวัน บทสนทนา ตอนจบ (ดูแผน)
- ปุ่ม E หน้าบ้านสลับภาพก่อน/หลังซ่อมเพื่อดูลุคเท่านั้น ยังไม่ใช้วัสดุ
- ยังไม่มีการชนวัตถุ เดินทะลุบ้านได้
- เซฟอยู่ใน localStorage ของเบราว์เซอร์นั้นเครื่องนั้น ล้างข้อมูลเว็บแล้วเซฟหาย, โหมดส่วนตัวอาจบันทึกไม่ได้ (เกมจะแจ้งเป็นข้อความ)
